## Generated unit and rock band names (prefix + suffix)
- Adjective prefixes use the Danish weak form without an article, so they fit any noun
  ("The Black" -> Sorte, "The Great" -> Store), giving e.g. "Sorte Drager".
- Noun prefixes become a genitive ("The Fire" -> Ildens, "The King's" -> Kongens, "The Sea" -> Havets).
- "The 1st" -> 1.; suffixes are capitalized Danish nouns (Bataljon, Husarer, Skarpskytter).
- Personal names and titles of nobility in the vampire set are kept or translated as titles
  (Greve, Grevinde, Hertug, Markis, Vojvode, Bojar; Lord/Lady kept).
- Rock band name parts are translated the same way (Vrede, Katte), with musical puns where possible
  (Major/Minor -> Dur/Mol, Power -> Strøm).
