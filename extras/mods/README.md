# Danish text for Civilization VI mods

Danish text for 13 popular user-interface mods. It only works together with the main Danish
package (the `da_DK` language must exist) and only shows for mods you have installed.

**Install:** copy the `.xml` files from `da_DK` here into the same
`Documents\My Games\Sid Meier's Civilization VI\Text\da_DK` folder as the main package.

| File | Mods (Steam Workshop id) |
|---|---|
| `Mods_da_DK.xml` (144 lines) | Better Loading Screen, Better Report Screen (1312585482), Better Tech Tree, Detailed Map Tacks (2428969051), More Lenses, Real Era Tracker, Real Great People |
| `Mods2_da_DK.xml` (57 lines) | Better Builder Charges Tracking (2409116842), Extended Policy Cards (2266952591), Policy Change Reminder (1132600299), Quick Deals (2460661464), Sukritact's Simple UI Adjustments (939149009) |
| `Mods3_da_DK.xml` (19 lines) | Detailed Wonder Reminder (2798127335) |

Translated from the mods' versions current in November 2026 and checked with
`tools/validate.py` against each mod's English text (0 errors). A few tooltips are written
directly into some mods' Lua code instead of their text files; those stay in English.
